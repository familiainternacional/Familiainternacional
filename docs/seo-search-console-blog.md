# SEO y Search Console — blog / perspectivas

## Flujo al publicar un artículo

1. Se crea la URL pública del artículo: `https://www.familiainternacional.cl/perspectivas/slug-del-articulo`.
2. Google descubre la URL vía sitemap o enlaces internos.
3. El artículo queda incluido automáticamente en `https://www.familiainternacional.cl/sitemap.xml`.

## Search Console

1. Ingresar a [Google Search Console](https://search.google.com/search-console).
2. Seleccionar la propiedad `https://www.familiainternacional.cl`.
3. En **Sitemaps**, enviar:
   `https://www.familiainternacional.cl/sitemap.xml`

## Buenas prácticas

- Título y meta description únicos por artículo.
- Imagen OG cuando aplique.
- Enlaces internos hacia servicios relacionados (`/servicios/...`).
